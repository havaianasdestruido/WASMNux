      Honest limitations

      • The CPU implements RV64IMAC today; Debian’s lp64d userspace also needs the F/D floating-point milestone (tracked in TODO.MD) before the Debian profile can run real userspace.
      • WebGPU accelerates framebuffer presentation only — it is not guest GPU passthrough and does not speed up the emulated CPU.
      • Guest networking needs a WebSocket relay (browsers expose no raw TCP/UDP). Without one, the guest is offline; apt network operations require the relay from Phase 9.
      • Guest assets (kernel, firmware, rootfs) are built by the pipeline in guest/ and served from /guest/…. The Boot button stays disabled until real assets are present.
      WASMNux is Apache-2.0. Architecture & test evidence live in the repository (docs/ARCHITECTURE.md, docs/TEST-REPORT.md, TODO.MD).
